# IntoSTL Brand Visual Reference

These two PNGs are VISUAL REFERENCES for implementation. They are not assets to embed directly into the production site.

## 1. Logo reference
File: `intostl-logo-reference.png`

Match this visual direction closely:
- three refined stacked rhombus/layer shapes
- top: teal/green
- middle: slightly lighter green/teal
- bottom: dark teal
- smooth, precise, balanced geometry
- generous but even negative space between layers
- wordmark `IntoSTL`
- `Into` dark teal, `STL` green/teal
- clean modern sans-serif
- no crude chevrons, no sharp V-like strips, no heavy industrial look

The production logo must be redrawn as clean SVG geometry. Do NOT rasterize this reference into the site.

## 2. Micro-icon reference
File: `intostl-micro-icons-reference.png`

Match the STYLE, not the exact semantic icons:
- pale mint circular background
- small, precise teal line icon centered inside
- elegant/light editorial feel
- consistent stroke weight and icon scale
- no filled pictograms
- no thick outlines
- no generic dashboard/icon-library appearance

For the homepage trust row, use this same visual style for:
- Browser-local
- No account
- Printable output

## Critical
Do not reinterpret the overall style. The existing implementation was too crude.
Use these images as the visual target, then implement production-ready SVG/CSS that closely matches them.
